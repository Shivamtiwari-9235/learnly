# Learnly — Mastery-First Mini Learning Platform

> Calm focus + playful reward. A portfolio-grade, browser-native EdTech platform.

## Features
- **Discovery & Onboarding: 4-step personalized onboarding with interest chips, daily goals, and deterministic SVG avatar creation.
- **Course Catalogue & Detail: Debounced search, category tabs, level/sort filters, URL-synced query params, outcomes, and expandable syllabus accordions.
- **Distraction-Free Lesson Player:Calm paper reading mode, collapsible,  mobile drawer, dark-slate code blocks with copy feedback, personal notes, bookmarks, `A-`/`A+` font sizing, and automatic resume.
- **Mastery Quiz Engine: Pure scoring logic ,  announcements, non-color-only option states, instant explanations, and reshuffled retries.
- **Gamification & Leaderboard: Deterministic XP, level rings, timezone-safe daily streaks, 10 rarity badges, and a 24-peer community leaderboard.
- **A4 Printable Certificate: Unlocks on 100% lesson completion + 70%+ quiz score; ivory/navy/gold A4 landscape `@media print` layout with deterministic local ID.
